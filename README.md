## 🎮 About

**Grave Shift** is a **multiplayer, task-based game** built with Unity.

Players work together to complete tasks around a graveyard while avoiding monsters. Players cannot attack monsters — **survival depends on teamwork, movement, and timing.**

---

## 🔄 Game Flow

**🏠 Host Lobby** → **👥 Invite Friends** → **🛠️ Complete Tasks** → **👹 Evade Monsters** → **❤️ Revive Players** → **🏆 Escape / Lose**

* Host a lobby and invite online friends
* Players receive different tasks
* Completing tasks can trigger monster encounters
* Evade monsters and revive fallen teammates
* **All tasks completed → Game Won**
* **Everyone defeated → Game Lost**

---

## ✨ Features

* 👥 Multiplayer with **Netcode for GameObjects**
* 🤝 **Friends & Invite System**
* 🏠 **Lobby + Relay**
* 🛠️ Task-based gameplay
* 👹 Dynamic monster encounters
* ❤️ Player revive system
* 🛍️ Skin shop with **Gem currency**
* 🏆 Achievement system
* ⚙️ Settings with customizable controls
* 📱 Mobile controls
